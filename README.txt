408 中断与异常 · 交互学习站

【运行方式】
1. 下载并解压本仓库，打开其中的 index.html。
2. 双击 HTML 文件，使用 Chrome、Safari 或 Edge 打开即可。
3. 完全离线运行，不需要安装 Python、Node.js，也不需要部署服务器。

【网站主要功能】
- 知识树总览：8 大模块，覆盖计组与操作系统中的中断和异常知识。
- 中断流程实验：逐步推进 7 个响应环节；切换 IF、IRQ 屏蔽、NMI、缺页异常，理解响应条件。
- 中断嵌套判断：通过优先级示例理解多重中断。
- 知识章节：详细考点讲解、易错提醒、章节笔记。
- 综合自测：20 道题，可按章节练习，自动评分与讲解。
- 错题本：提交测验后自动收集错题，可单独重练。
- 进度记录：标记章节已掌握，统计学习进度。
- 搜索：使用页面顶部搜索框；Mac 为 Command+K，Windows 为 Ctrl+K。

【数据保存与限制】
- 进度、笔记和错题保存在当前浏览器的 localStorage 中。
- 不同浏览器、不同设备之间不会自动同步。
- 某些浏览器对 file:// 页面存储存在特殊限制；如存储失败或清除浏览器网站数据，学习记录可能丢失。
- 可以使用章节右上角“打印 / 导出 PDF”保存离线笔记（浏览器打印功能）。

【内容说明】
- 内容以全国硕士研究生招生考试 408 的经典模型和考查范围为主。
- 对 2021 年“进入中断响应周期时 CPU 开中断”的表述，特别标注教材判题语境与严格解释的歧义。
- 具体不同 CPU 架构的细节可能不同，以考试教材和题目明确约定为准。
